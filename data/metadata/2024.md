### EoH

| 字段 | 内容 |
|---|---|
| 标题 | Evolution of Heuristics: Towards Efficient Automatic Algorithm Design Using Large Language Model |
| 机构 | 香港城市大学；华为诺亚方舟实验室；南方科技大学 |
| 摘要 | 启发式方法被广泛用于处理复杂的搜索与优化问题。然而，人工设计启发式往往非常耗费人力，并且需要丰富的实践经验和专业知识。本文提出Evolution of Heuristic（EoH），一种新颖的进化范式，它同时利用大语言模型（LLM）和进化计算（EC）方法来实现自动启发式设计（AHD）。EoH用自然语言表示启发式的思想，称为"thoughts"，然后由LLM将其翻译为可执行代码。在一个进化搜索框架中同时对思想和代码进行进化，使该方法在生成高性能启发式方面非常有效且高效。在三个被广泛研究的组合优化基准问题上的实验表明，EoH的表现优于常用的人工设计启发式以及包括FunSearch在内的其他近期AHD方法。特别地，在计算预算较低（以对LLM的查询次数衡量）的情况下，EoH为在线装箱问题生成的启发式显著优于被广泛使用的人工设计基线算法。 |
| 代码 | https://github.com/FeiLiu36/EoH |
| 对比方法 | 在线装箱：First Fit、Best Fit、FunSearch；TSP：NI、FI、Or-Tools、AM（Attention Model）、POMO、LEHD；FSSP：GUPTA、CDS、NEH、NEHFF、PFSPNet、PFSPNet+NEH；消融变体：EoC（仅代码无思想）、EoH-e1（仅E1）、EoH-e2（仅E1+E2） |

### TROVE

| 字段 | 内容 |
|---|---|
| 标题 | TroVE: Inducing Verifiable and Efficient Toolboxes for Solving Programmatic Tasks |
| 机构 | Language Technologies Institute, Carnegie Mellon University |
| 摘要 | 语言模型（LM）可以通过编写程序来解决诸如回答关于表格或图像的问题等任务。然而，使用基础函数常导致程序冗长且容易出错，而高层函数又需要专家设计。为了在无需人力的情况下获得更好的解决方案，我们让代码语言模型自行整理可复用的高层函数，并用它们来编写解决方案。我们提出TROVE，一种训练无关（training-free）的方法，通过生成使用、扩充以及周期性裁剪工具箱，来归纳出可验证且高效的函数工具箱。在来自数学、表格问答和图像推理任务的11个数据集上，与基线相比，TROVE持续产生更简洁且准确率更高的解决方案，同时工具箱规模缩小79%-98%，并使人工验证速度提升31%、准确率提升13%。 |
| 代码 | https://github.com/zorazrw/trove |
| 对比方法 | PRIMITIVE（仅用内置基础函数）；INSTANCE（为每条实例单独生成函数，不复用/不裁剪） |

| 机构 | University of California, Irvine；Allen Institute for AI |
| 摘要 | 大语言模型（LLM）近来已被用于交互式环境中的序贯决策任务。然而，如何利用环境奖励信号来持续改进LLM执行者的表现并非易事。我们提出了技能集优化方法（Skill Set Optimization, SSO），通过构建和精炼一组可迁移的技能来提升LLM执行者的表现。SSO通过提取具有高奖励的公共子轨迹，并为每项技能生成子目标和指令，从而构建技能。这些技能以上下文方式提供给LLM执行者，用以强化能带来高奖励的行为。随后，SSO进一步通过剪除那些不再持续带来高奖励的技能来精炼技能集。我们在NetHack和ScienceWorld中评估了本方法：在自定义NetHack任务中，SSO的表现比基线方法高出40%；在ScienceWorld中，比此前最先进方法高出35%。 |
