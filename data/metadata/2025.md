### Agent Laboratory

| 字段 | 内容 |
|---|---|
| 标题 | Agent Laboratory: Using LLM Agents as Research Assistants |
| 机构 | AMD；Johns Hopkins University；ETH Zurich |
| 摘要 | 长期以来，科学发现一直是一个漫长而昂贵的过程，从最初构思到最终结果需要耗费大量时间与资源。为加速科学发现、降低研究成本并提升研究质量，我们提出了Agent Laboratory——一个能够完成整个研究流程的自主LLM框架。该框架接受人类提供的研究想法，并依次经历文献综述、实验和报告撰写三个阶段，产出包括代码仓库和研究报告在内的完整研究成果，同时允许用户在每个阶段提供反馈和指导。我们将Agent Laboratory部署在多种最先进的LLM上，并邀请多位研究者参与调查以评估其质量：他们在研究过程中提供人类反馈进行引导，并对最终论文进行评估。我们发现：（1）由o1-preview驱动的Agent Laboratory能产出最佳的研究成果；（2）生成的机器学习代码相较于现有方法能够达到最先进的性能；（3）人类在每个阶段提供反馈的参与显著提升了研究的整体质量；（4）与此前的自主研究方法相比，Agent Laboratory能将研究开支降低84%。我们希望Agent Laboratory能使研究者将更多精力投入到创造性构思而非底层编码与写作中，从而最终加速科学发现的进程。 |
| 代码 | https://github.com/SamuelSchmidgall/AgentLaboratory |
| 对比方法 | MLAB / ResearchAgent（来自MLAgentBench）、OpenHands / CodeActAgent、AIDE（三者均为MLE-Bench上与mle-solver对比的ML求解器基线）；此外在成本/效率方面与此前的自主研究工作流（The AI Scientist）进行了比较 |

| 摘要 | 大语言模型作为相互交互与协作的多个智能体加以运用，已在解决复杂任务方面表现出色。这些智能体由声明其功能的提示编程，并配合协调各智能体间交互的拓扑。为多智能体系统设计提示和拓扑本质上是复杂的。我们首先进行了深入的设计空间分析，发现提示与拓扑共同在使多智能体系统设计更有效方面发挥关键作用。基于这些洞见，我们提出了Multi-Agent System Search（Mass），通过交织其优化阶段——从局部到全局、从提示到拓扑——在三个阶段（模块级提示优化、工作流拓扑优化、工作流级提示优化）高效利用复杂的设计空间。我们证明，经Mass优化的多智能体系统以显著优势超越了一系列现有的替代方案。 |

### Dynamic-Cheatsheet

| 字段 | 内容 |
|---|---|
| 标题 | Dynamic Cheatsheet: Test-Time Learning with Adaptive Memory |
| 机构 | Stanford University；Together AI |
| 摘要 | 尽管当前的语言模型在复杂任务上表现出色，但它们通常是孤立地运行的：每个输入查询都被单独处理，而不会保留先前尝试中的经验。本文提出Dynamic Cheatsheet（DC），一个为黑盒语言模型赋予持久性、可演化记忆的轻量级框架，使模型能够存储并复用积累的策略、代码片段和通用问题解决经验，而不是反复重新发现或重复犯同样的错误。这种测试时学习方式在无需显式真实标签或人工反馈的情况下，大幅提升了模型在一系列任务上的表现：借助DC，Claude 3.5 Sonnet在AIME数学考试上的准确率提高了一倍以上；GPT-4o在Game of 24拼图任务中的成功率从约10%提升到99%；在方程配平等易出错的算术任务中，DC使GPT-4o和Claude达到接近完美的准确率，而基线停滞在约50%；在GPQA-Diamond上Claude提高了9%，在MMLU-Pro工程和物理学科目上提升最多达8%。DC的记忆是自我整理的，聚焦于简洁、可迁移的片段而非完整对话记录，能在不修改底层参数的情况下动态调整语言模型的问题解决能力。 |
| 代码 | http://github.com/suzgunmirac/dynamic-cheatsheet |
| 对比方法 | Baseline prompting（无记忆基线）；DC-∅（结构化提示但空记忆）；Full-History Appending；Dynamic Retrieval（仅检索不整理）；Majority Voting（仅AIME） |

### DGM

| 字段 | 内容 |
|---|---|
| 标题 | Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents |
| 机构 | University of British Columbia；Vector Institute；Sakana AI；Canada CIFAR AI Chair |
| 摘要 | 当今大多数人工智能系统都受限于人工设计的固定架构，无法自主且持续地自我改进。哥德尔机提出了一种理论上的替代方案：一种能够以可证明有益的方式反复修改自身的自我改进型人工智能，但在实践中要证明大多数改动净收益为正是不可能的。我们提出达尔文哥德尔机（DGM），一种新颖的自我改进系统，它迭代地修改自身代码（从而也提升了其修改自身代码库的能力），并使用编码基准对每次改动进行实证验证。受达尔文进化论和开放式探索研究的启发，DGM维护并扩充着一个已生成编码智能体的存档，从中采样智能体使其自我修改以创造出新的、有趣的自身版本，形成一棵不断生长的、多样化且高质量的智能体树。实证结果表明，DGM能够自动提升其编码能力（如更好的代码编辑工具、长上下文窗口管理、同行评审机制），使其在SWE-bench上的表现从20.0%提升到50.0%，在Polyglot上从14.2%提升到30.7%，显著优于没有自我改进或开放式探索的基线方法。所有实验均在安全预防措施下进行（沙盒隔离、人工监督）。 |
| 代码 | https://github.com/jennyzzt/dgm |
| 对比方法 | DGM w/o self-improve（复现ADAS做法）；DGM w/o open-ended exploration（不维护存档）；Checked Open-sourced SoTA（SWE-bench手工基线）；Aider（Polyglot手工基线） |
